# Branching Minds

> Branching Minds is a K-12 education-technology company providing an MTSS (Multi-Tiered System of Supports) and RTI (Response to Intervention) software platform. It centralizes student data, intervention planning, progress monitoring, attendance, and behavior support for school districts, integrating with district SIS, universal screeners, and assessment tools via nightly data syncs. Branching Minds does not currently publish a public developer API; integration is handled through file upload, secure SFTP, and managed data connections.
